# 빛사냥 — 영화창작 동아리 홈페이지

A24의 공개 CSS와 실제 화면에서 색상·타입·간격·버튼·반응형 규칙을 추출해 적용한 빛사냥 홈페이지입니다. 경희대학교 중앙 영화창작 동아리 빛사냥의 실제 공개 영상 61편을 담았습니다. HTML·CSS·JavaScript로만 동작하며 설치, 빌드, API 키, 서버 프로그램이 필요하지 않습니다.

## 포함된 화면과 기능

- 「from.승연」과 「내 몸 뺏어놓고」의 연속 대표 이미지, 이미지 위 내비게이션과 대형 제목
- 실제 공개 영상 61편의 로컬 썸네일, 제목, 간단한 설명, 재생 시간, YouTube 링크
- 이미지/목록 전환, 작품 종류와 공개·제작 연도 필터, 제목·설명 검색, 9편씩 더보기
- 작품 상세창, 원본 영상 설명, YouTube 감상 링크
- 정기영화·빛무리 영화제·메이킹·영화제 출품 활동 소개
- 1988년 창립 및 공식 채널에서 확인한 2023~2026년 활동 기록
- 모바일 메뉴, 작은 화면의 2열 이미지 및 행 목록, 키보드로 조작 가능한 상세창

## 열어보기

`index.html`을 브라우저로 열면 됩니다. 파일을 옮길 때는 `assets/`, `data.js`, `script.js`, `style.css`도 함께 옮겨주세요.

로컬 서버를 사용하려면 이 폴더에서 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. Python은 이 미리보기 방식에만 쓰이며 실제 사이트 운영에는 필요하지 않습니다.

## GitHub Pages에 올리기

1. GitHub 저장소의 배포할 브랜치(예: `main`)에 **이 폴더 안의 파일들**을 넣습니다. `index.html`이 저장소 최상위에 있어야 합니다. `assets/`의 폴더 구조와 `.nojekyll` 파일도 유지합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment → Source → Deploy from a branch**를 선택합니다.
4. 브랜치를 `main`, 폴더를 `/(root)`로 선택하고 **Save**를 누릅니다.
5. 배포가 끝나면 Pages 설정에 표시되는 사이트 주소로 접속합니다.

프로젝트 저장소의 하위 경로에서도 이미지와 스크립트가 동작하도록 모든 내부 경로를 상대 경로로 작성했습니다. 현재 제공물은 로컬 완성본이며, 특정 GitHub 저장소에 업로드하거나 공개 배포하지 않았습니다.

공식 안내: [GitHub Pages 배포 소스 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 내용 수정

### 작품 추가·수정: `data.js`

화면에 사용하는 작품 데이터의 원본은 `data.js`의 `window.SITE_DATA.films` 배열입니다. 기본 정렬은 제작 연도·학기의 최신순입니다. 같은 학기는 공개일 최신순으로 정렬합니다. 기존 객체 하나를 복사해서 수정하면 됩니다.

```js
{
  "id": "실제 YouTube 영상 ID",
  "originalTitle": "유튜브에 올라간 원본 제목",
  "duration": "12:30",
  "image": "assets/new-film.jpg",
  "url": "https://www.youtube.com/watch?v=실제영상ID",
  "description": "원본 영상 설명",
  "published": "2026-11-09",
  "title": "홈페이지에 표시할 작품명",
  "category": "정기영화",
  "year": "2026",
  "yearSource": "title",
  "semester": 2,
  "semesterSource": "title",
  "productionTerm": "2026-2",
  "publishedYear": "2026",
  "label": "2026-2학기 정기영화",
  "summary": "작품을 소개하는 한두 문장.",
  "award": ""
}
```

- `category`는 `정기영화`, `빛무리 영화제`, `영화제 출품작`, `메이킹`, `동아리 기록` 중 하나를 사용합니다.
- 썸네일은 `assets/`에 저장하고 경로를 적습니다.
- `year`는 제목에서 확인되는 제작 학년도를 우선 사용했고, 없는 경우 공개 연도를 사용했습니다. 업로드 시기와 제작 연도가 다를 수 있습니다.
- `summary`는 공식 영상 설명을 바탕으로 요약했습니다. 줄거리 정보가 없는 작품에는 정기영화 정보만 넣었습니다.
- `description`은 원본 설명이며 상세창의 ‘원본 영상 설명’에서 볼 수 있습니다.
- `films.json`은 현재 수록 영상을 외부 도구로 재사용할 수 있도록 제공하는 JSON 사본입니다. 홈페이지는 이 파일을 읽지 않습니다. 사이트 수정은 `data.js`에서 하세요.
- 작품 수와 연도 선택 항목은 자동 갱신됩니다. 카테고리 자체를 새로 만들려면 `index.html`의 필터 버튼도 추가합니다.
- 영상 자동 수집이나 실시간 갱신은 하지 않습니다. 새 작품은 운영자가 파일에 추가합니다.

### 소개·활동·연혁: `index.html`

`#about`, `#history`, `#next` 영역의 문구와 링크를 수정합니다. 과거 전체 연혁을 확보한 상태는 아니므로, 현재는 확인 가능한 창립 연도와 최근 활동 기록만 실었습니다. 운영진이 가진 연혁을 추가하면 됩니다.

모집 기간·지원 조건·담당자 이메일·인스타그램·지원 폼은 확인되지 않아 넣지 않았습니다. 실제 모집 링크를 받으면 `#next`의 버튼을 바꾸고 문구를 수정할 수 있습니다.

### 색상·레이아웃: `style.css`

맨 위 `:root`의 `--color-*`, `--paper`, `--ink` 변수를 바꾸면 색상을 변경할 수 있습니다. 외부 웹폰트 없이 A24의 Arial 대체 글꼴 보정 규칙과 기기에 설치된 한글 산세리프를 사용합니다.

추출한 원본 값과 적용 내용을 정리한 `A24-DESIGN-SYSTEM.md`, 원본 색상·모션 토큰과 실측값을 담은 `a24-design-tokens.json`도 포함되어 있습니다.

### 대표 작품

`index.html`의 `#top`에 있는 제목, 연도, 이미지 대체 텍스트, 감상 링크를 바꿉니다. 고해상도 이미지는 `assets/hero.jpg`이며, `<head>`의 preload 경로도 같은 파일을 가리킵니다.

## 자료와 출처

수집일: **2026년 11월 9일**. 채널 동영상 탭의 마지막 페이지까지 **4페이지, 총 98개**를 확인했습니다. 이 중 **2023년 1월 1일 이후 공개된 61개**를 모두 수록했습니다. 2023년 17개, 2024년 19개, 2025년 10개, 2026년 15개입니다. 범위 밖인 2022년까지 공개된 영상 37개는 제외했습니다.

- 기준은 YouTube의 `publishDate`이며, 제목의 제작 학년도와 구분합니다. 2022년에 제작해 2023년 또는 2024년에 공개한 작품도 포함합니다.
- 첫 영상 공개일은 2023-01-03, 가장 최근은 2026-11-04입니다.
- 연도 필터와 정렬은 기본적으로 **제작·활동 연도**를 사용하며, **공개 연도**로 전환할 수 있습니다. 학기가 확인된 작품은 2학기 → 1학기 순으로 정렬하고, 학기를 확인하지 못한 영상은 같은 연도의 학기 확인 작품 뒤에 표시합니다. 공개 연도 보기에서는 공개일 최신순으로 정렬합니다. 제작 연도는 제목 → 영상 설명 → 공개 연도 순으로 판단하고 `yearSource`에 기록했습니다.
- `archive-manifest.json`은 전체 98개 영상의 ID·제목·공개일·포함 여부와 연도별 수록 수를 담습니다. 포함 영상 ID 집합과 홈페이지 데이터가 일치하는지 패키징 때 검증합니다.
- 2023년 창립 35주년 인터뷰와 제1·2회 빛무리 영화제 기록을 연혁에 추가했습니다.

- 동아리명·소속·창립 연도: [빛사냥 공식 YouTube 채널](https://www.youtube.com/@%EB%B9%9B%EC%82%AC%EB%83%A5-o4y)
- 작품 정보·썸네일·원본 설명: 각 작품의 `url` 필드에 기재한 공식 채널 영상
- 제4회 활동: [In Sync](https://www.youtube.com/watch?v=cTYXi072ATk)
- 제5회 활동: [마녀](https://www.youtube.com/watch?v=VS7rihVkb3w)
- 제6회 활동: [그녀를 지웁니다](https://www.youtube.com/watch?v=m-vb4xrvy4A)
- 제7회 활동: [살아남으려 했을 뿐이다](https://www.youtube.com/watch?v=V3I1RAVv0g8)

## 동아리 로고

사용자가 제공한 BIT HUNT 로고를 헤더·푸터·사이트 아이콘에 적용했습니다. `assets/logo-black.svg`는 원본 PNG를 내장하고 RGB만 검정으로 표시하는 SVG 래퍼입니다. 원본의 형태와 알파 투명도를 보존하고, 투명한 바깥 여백만 viewBox로 정리했습니다. 로고 주변 배경은 투명합니다. 헤더는 검정 로고, 어두운 푸터는 CSS 반전으로 흰 로고를 표시합니다.

## 빛무리 영화제 수상작 보기

상단과 모바일 메뉴의 **빛무리 수상작**은 작품 목록으로 이동하면서 빛무리 영화제·수상작 필터를 켭니다. `#bitmuri-awards` 주소로 직접 들어가도 같은 화면이 열립니다.

- 빛무리 영화제 분류를 선택하면 **회차 선택**과 **전체 작품 / 수상작만** 버튼이 표시됩니다.
- 회차는 최신 회차부터 표시하며, 회차별 주제와 제작·활동 기간을 함께 적었습니다.
- 빛무리 영화제 안에서는 최신 회차 → 대상 → 최우수상 → 우수상 → 그 외 작품 순입니다. 같은 상을 받은 작품도 모두 표시합니다.
- 수상작에는 이미지 아래에 얇은 테두리의 수상명이 표시됩니다. 목록 보기와 상세창에서도 수상 정보를 확인할 수 있습니다.
- `festivalEdition`은 회차, `awardName`은 대상·최우수상·우수상 중 확인된 상입니다. 기존 `award`에는 원본에서 수집한 표현을 유지했습니다. `festivals` 배열에는 회차·주제·기간이 있습니다.
- 수상 정보는 **공식 영상 제목·설명에 기록된 내용**만 반영했습니다. 기록이 없는 작품을 미수상으로 단정하지 않습니다. 수상작이 표시되지 않는 회차는 전체 작품으로 돌아갈 수 있습니다.
